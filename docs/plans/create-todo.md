## 2. 关键实现约定

**分层与存储接口**

service 依赖的非导出接口 `todoStore` 定义在 `service.go` 内，仅包含：

```go
Create(todo Todo) (Todo, error)
```

service 负责规范化和校验标题、设置 `done=false`、生成 UTC 创建时间；store 负责生成 ID 和保存记录。store 使用互斥锁保护递增 ID 与内存集合。无需增加查询方法；测试在同包内检查存储内容。

**JSON 解析**

使用 `json.Decoder` 将请求解码为 `map[string]json.RawMessage`：

1. 解码失败或结果为 `nil` 时拒绝，确保请求是 JSON 对象，排除顶层 `null`。
2. 再次解码，必须得到 `io.EOF`，允许尾随空白，拒绝第二个 JSON 值或其他尾随内容。
3. 遍历字段名，只允许精确匹配 `title`。`Title`、`TITLE` 及其他字段均作为未知字段返回 400。
4. 用 map 查询结果区分 `title` 缺失。
5. 去除原始值周围空白后，判断是否为 JSON `null`，单独拒绝。
6. 将原始值解码为字符串；数字、布尔、数组、对象等类型解码失败时返回 400。
7. 将字符串交给 service，执行首尾空白清理和码点长度校验。

不会直接解码到请求结构体，避免结构体字段匹配接受大小写变体。

**响应与路由**

- 使用标准库 `ServeMux` 注册 `POST /todos`。
- 成功返回 201；请求错误返回 400；内部错误返回 500。三者均使用统一 JSON 包装。
- 500 响应不暴露底层错误详情；底层错误按项目约定包装并记录。
- 404/405 保持标准库默认行为，不添加自定义 JSON 包装。

## 3. 实施步骤及独立验证

1. **实现模型和内存 store。**  
   验证保存内容、返回值副本、重复创建，以及并发写入数量和 ID 唯一性。

2. **实现 service 及其 store 接口。**  
   验证标题规范化、长度边界和默认值；使用测试存储确认无效输入不调用 `Create`，故障返回可通过 `errors.Is` 识别。

3. **实现 handler 和 JSON 解析。**  
   用表驱动 HTTP 测试验证成功、全部请求错误、大小写字段名及 500 兜底；检查失败请求无写入。

4. **接入程序入口。**  
   组装一份共享 store，监听 `:8080`。启动实际服务，提交合法、非法及重复请求，核对响应和不同 ID。

5. **执行最终检查。**  
   运行 `make check` 并报告实际结果。  
   同时运行 `git diff --stat`、`git status --short --untracked-files=all` 和 `git diff -- go.mod`，结合初始状态确认新增、修改文件与计划一致，且 go.mod 未变。`git status` 用于补充显示尚未跟踪的新文件。

## 4. 验收标准对应测试

| 验收条目 | 测试内容 |
| --- | --- |
| 1. 成功响应 | 断言 201、JSON Content-Type、`code=0`、`msg=ok` 和全部四个数据字段及类型 |
| 2. 空白处理 | 覆盖空格、制表符、换行及内部空白；比较响应标题与保存标题 |
| 3. 长度边界 | 覆盖 1、100、101 个码点、100 个中文字符及带首尾空白的边界标题 |
| 4. 非法请求 | 覆盖空体、非法 JSON、顶层 `null`/数组/标量、连续 JSON 值、尾随垃圾、缺失标题、空白标题及各类非字符串值；断言 400、错误包装、`data=null` 且无写入 |
| 5. 未定义字段 | 分别测试 `done`、`id`、`created_at`、任意其他字段、`Title`、`TITLE`，以及 `title` 与大小写变体同时出现；均返回 400 且无写入 |
| 6. 服务端字段 | 检查 ID 非空且唯一、`done=false`、创建时间处于调用时间区间内，响应时间可按 RFC3339 解析 |
| 7. 重复提交 | 相同标题提交两次，均返回 201，产生两个不同 ID 和两条记录 |
| 8. 共享与并发 | 不同客户端共享同一 store；并发请求后核对数量和 ID 唯一性，并运行竞态检查 |
| 9. 项目约定 | 检查分层、入口职责和标准库依赖；测试错误包装；确认测试为表驱动且与源文件同目录 |

补充回归测试：内部存储错误返回统一 JSON 500；未匹配路径、错误方法分别返回标准库的 404/405，不断言自定义响应体。
