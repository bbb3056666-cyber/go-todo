---
name: review-checklist
description: 对当前分支的代码改动做只读审查。当用户要求 review、代码审查、检查改动质量时使用。不用于修改代码。
---

按以下步骤执行，全程只读，不修改任何文件，不执行 git commit。

1. 确定审查范围：当前分支相对主分支的 diff（先用 git branch 确认主分支名，可能是 main 或 master）。
2. 读取 docs/review-checklist.md 作为审查依据，并读取对应的 Spec 和 AGENTS.md。
3. 第一步输出：逐项列出清单条目适用或不适用，不适用的写一句原因。
4. 第二步输出：只审适用的条目，按 高/中/低 分级，每条给出文件、函数、问题和修复建议。
5. 不确定的标注"不确定"，不要为凑数编造问题。
